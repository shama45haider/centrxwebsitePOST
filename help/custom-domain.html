Step-by-step for your provider

Pick where your domain is managed to see where its DNS records live and what to type in each box. The records themselves come from Centrx: here’s how to get them.

GoDaddy

  1. Sign in to GoDaddy, open your domain list and select your domain.
  2. Open the DNS tab and select Add New Record.
  3. Choose the Type Centrx shows. In Name, enter the host from Centrx, like cx1._domainkey, or @ for the SPF record. Paste the Value and leave TTL as it is.
  4. Select Save, then add the next record. Add More Records lets you add several before saving.

GoDaddy adds your domain to the end of the name, so enter cx1._domainkey, not cx1._domainkey.yourbusiness.com. On GoDaddy's older screen, it's Edit DNS in the menu next to your domain, then Add. If GoDaddy says your domain uses other nameservers, add the records with that company instead.

Namecheap

  1. Sign in, open Domain List and select Manage next to your domain.
  2. Open the Advanced DNS tab. Under Host Records, select Add New Record.
  3. Choose TXT Record or CNAME Record, enter the Host and paste the Value. Leave TTL on Automatic.
  4. Select Save all changes, then add the next record.

Namecheap adds your domain to the host for you: enter cx1._domainkey for DKIM and @ for SPF. If Host Records is missing or locked, your domain uses another company's nameservers (often your web host's), so add the records there.

Squarespace

  1. Open your Domains dashboard and select your domain.
  2. Select DNS, then DNS Settings, and scroll to Custom records.
  3. Select Add record. Squarespace may ask for your password or two-step code first.
  4. Choose the Type, enter the Name (@ for the SPF record) and paste the value into Data. Select Save, then add the next record.

Custom records only work when your domain uses Squarespace's nameservers. If the domain is only connected to Squarespace and was bought somewhere else, add the records there. If you see Custom record not saved, a record with the same name probably exists already. That's often an old SPF record, so edit that one instead.

Cloudflare

  1. Sign in and select your domain.
  2. Go to DNS, then Records, and select Add record.
  3. Choose the Type, enter the Name and paste the Target (for CNAME) or Content (for TXT).
  4. For CNAME records, turn Proxy status off so it shows DNS only. Then select Save.

The DKIM records must be DNS only (grey cloud). If they're proxied (orange cloud), inboxes can't read them and verification fails. TXT records are always DNS only. Cloudflare changes usually show up within a few minutes.

Porkbun

  1. Sign in to Domain Management.
  2. Next to your domain, select Details, then the edit icon next to DNS Records.
  3. In the form at the top, choose the Type, enter the Host and paste the value into Answer. For records Centrx shows as @, leave Host empty.
  4. Select Add, then add the next record.

Porkbun shows your domain next to the Host box, so type only the part before it: cx1._domainkey for DKIM, _dmarc for DMARC and nothing at all for SPF.

Wix

  1. Go to Domains in your Wix account.
  2. Select the Domain Actions menu next to your domain, then Manage DNS Records.
  3. In the TXT or CNAME (Aliases) section, select + Add Record.
  4. Enter the Host Name and Value, then select Save. For records Centrx shows as @, leave Host Name empty.

You can only add records in Wix if your domain is connected to Wix by name servers. If it's connected by pointing, add the records where you bought the domain.

Other providers

Every DNS screen works the same way, but the boxes have different names. Look for a page called DNS, DNS records, DNS zone or Advanced DNS, add a record, and match the boxes like this:

In CentrxYour provider may call it
TypeType, Record type
HostName, Host, Host name, Record name
ValueValue, Points to, Target, Content, Data, Answer

@ means your main domain. Some providers want you to type @, and others want the box left empty. If the provider shows your domain next to the box, type only the part before it.

Not sure who manages your DNS? Look up your domain's nameservers with any free DNS lookup site. Nameservers ending in domaincontrol.com are GoDaddy, registrar-servers.com is Namecheap, ns.cloudflare.com is Cloudflare, porkbun.com is Porkbun and wixdns.net is Wix. Add the records at that company.

Who can use this

Sending from your own domain is Business Email, an add-on for any plan at $9/month per domain. Business and Enterprise will be able to connect with one click (coming soon). On every plan, you can follow the steps below. Without it, email comes from notify@centrx.co with your business name as the sender, and it works without any setup.

What to have ready

  • A domain you own, like yourbusiness.com.
  • A sign-in for the place that manages its DNS. That's usually where you bought the domain, such as GoDaddy, Namecheap, Squarespace or Cloudflare.

If someone else set up your website, ask them to add the records for you. It takes them a few minutes.

Connect your domain

  1. In Centrx, open Settings → Business Email.
  2. Enter your domain and the address to send from, for example notifications@yourbusiness.com.
  3. Centrx shows four DNS records. Copy each one into your domain's DNS settings exactly as shown. See the steps for your provider.
  4. Back in Centrx, select Verify.

The records look like this. Centrx shows the exact values for your domain, with a copy button next to each one.

TypeHostValue
TXT@v=spf1 include:mail.centrx.co ~all
CNAMEcx1._domainkeycx1.yourbusiness-com.dkim.centrx.co
CNAMEcx2._domainkeycx2.yourbusiness-com.dkim.centrx.co
TXT_dmarcv=DMARC1; p=none; rua=mailto:dmarc@yourbusiness.com

DNS changes often show up within minutes, but can take up to 48 hours. If verification doesn't pass straight away, try again later. Confirm: email keeps sending from notify@centrx.co until the domain is verified.

What the records do

RecordTypeWhat it does
SPFTXTLists who is allowed to send email for your domain.
DKIMCNAME or TXTSigns each email so inboxes can tell it really came from you.
DMARCTXTTells inboxes what to do with email that fails those checks.

Together they keep your email out of spam folders and stop others from sending email that pretends to be you.

Good to know

  • Already have an SPF record? A domain can only have one. Don't add a second. Add include:mail.centrx.co to the one you have, just before ~all or -all. Or ask us and we'll tell you exactly what it should say.
  • Already have a DMARC record? Keep yours and skip ours. One is enough.
  • Adding all four at once is fine. Centrx checks them together when you select Verify.

If verification fails

  • Wait an hour and try again. Most failures are DNS that hasn't updated yet.
  • Check for typos and extra spaces, and make sure the value wasn't put in quotes twice.
  • Check there's only one SPF record.
  • Make sure you edited the DNS where the domain's records actually live. If you moved DNS to another provider, edit it there.
